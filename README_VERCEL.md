# Vercel Deployment Guide

## Prerequisites
- Vercel account (https://vercel.com)
- GitHub repository linked to Vercel
- Environment variables configured

## Deployment Steps

### 1. Push to GitHub
```bash
git add .
git commit -m "Add Vercel configuration"
git push origin main
```

### 2. Connect to Vercel
- Go to https://vercel.com
- Click "Add New" → "Project"
- Select your GitHub repository
- Click "Import"

### 3. Configure Environment Variables
In Vercel Dashboard:
1. Go to your project settings
2. Navigate to "Environment Variables"
3. Add all your `.env` variables:
   - `MONGODB_URI` - MongoDB connection string
   - `JWT_SECRET` - JWT secret key
   - `GOOGLE_GENERATIVE_AI_KEY` - Google AI API key
   - `GROQ_API_KEY` - Groq API key
   - `CLOUDINARY_CLOUD_NAME` - Cloudinary credentials
   - `CLOUDINARY_API_KEY` - Cloudinary API key
   - `CLOUDINARY_API_SECRET` - Cloudinary API secret
   - `EMAIL_USER` - Email for nodemailer
   - `EMAIL_PASS` - Email password
   - `PORT` - (Optional) Set to 3001 or your preferred port
   - Any other variables from your `.env` file

### 4. Deploy
- Vercel will automatically build and deploy when you push to your main branch
- Deployment happens automatically on each push
- Monitor deployment status in Vercel Dashboard

## Project Structure for Vercel
```
.
├── src/                 # TypeScript source files
├── dist/                # Built JavaScript (generated by build)
├── package.json         # Project dependencies
├── tsconfig.json        # TypeScript config
├── vercel.json          # Vercel configuration (root level)
└── .vercelignore        # Files to ignore during deployment
```

## Build & Start Scripts
The project uses:
- **Build**: `npm run build` - Compiles TypeScript to JavaScript
- **Start**: `npm start` - Runs the compiled server

## Important Notes

1. **Node.js Runtime**: Vercel supports Node.js 20.x or later
2. **Timeout**: Functions have a 30-second timeout limit
3. **Memory**: Functions are allocated 1024MB by default
4. **PORT**: The app listens on the PORT environment variable (defaults to 3001)
5. **Database**: Ensure your MongoDB URI is accessible from Vercel servers

## Troubleshooting

### Build Fails
- Check `vercel logs` for error messages
- Ensure all dependencies are in `package.json`
- Verify TypeScript configuration in `tsconfig.json`

### Environment Variables Not Working
- Double-check variable names match what's used in code
- Rebuild/redeploy after adding new variables
- Use `process.env.VARIABLE_NAME` in code

### Database Connection Issues
- Verify MongoDB connection string is correct
- Check IP whitelist in MongoDB Atlas
- Ensure credentials are correct in environment variables

### Performance Issues
- Monitor function duration in Vercel Analytics
- Consider caching strategies
- Optimize database queries

## Custom Domain
1. In Vercel Dashboard, go to project settings
2. Navigate to "Domains"
3. Add your custom domain
4. Follow DNS instructions provided

## Monitoring
- Access logs: `vercel logs <project-name>`
- View analytics in Vercel Dashboard
- Set up error alerts and notifications
